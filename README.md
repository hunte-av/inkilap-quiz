# 🇹🇷 İnkılap Tarihi (1–7. Ünite) Akıllı Tekrar & Ustalaşma Sistemi

1. Üniteden 7. Üniteye kadar olan **68 Konu Kavrama Sorusunu** içeren, yanlış yapılan soruları doğru cevaplayana kadar sonraki turlarda tekrar soran ve tamamı bitince baştan karışık sırayla başlatan interaktif çalışma uygulaması (PWA).

## 📱 Telefondan Kullanım ve Kurulum (iOS & Android)
1. **Canlı Bağlantıyı Aç:** 👉 **[https://hunte-av.github.io/inkilap-quiz/](https://hunte-av.github.io/inkilap-quiz/)**
2. **Uygulama Olarak Telefona Kur:**
   - **Android (Chrome):** Sağ üstteki `📲 Kur` butonuna veya tarayıcı menüsünden **"Uygulamayı Yükle / Ana ekrana ekle"** seçeneğine dokun.
   - **iPhone (Safari):** Alt ortadaki **Paylaş** (kare ve yukarı ok) simgesine dokun ve **"Ana Ekrana Ekle"** seçeneğine bas.
   - Kurulduktan sonra internetin olmasa bile (Offline) telefonunda tam ekran uygulama olarak çalışır!

## 💻 Bilgisayara Kurulum

### Yöntem 1: Tek Tıkla Masaüstü Uygulaması (PWA) Olarak Kurulum
- **[https://hunte-av.github.io/inkilap-quiz/](https://hunte-av.github.io/inkilap-quiz/)** adresini Chrome veya Edge ile aç.
- Sağ üstteki **"📲 Uygulamayı Kur"** butonuna (veya adres çubuğunun sağındaki yükle simgesine) tıkla.

### Yöntem 2: GitHub'dan İndirip Çevrimdışı Çalıştırma
```bash
git clone https://github.com/hunte-av/inkilap-quiz.git
cd inkilap-quiz
# Doğrudan tarayıcıda aç:
xdg-open index.html   # Linux
# veya Windows'ta: start index.html
# veya Mac'te: open index.html
```
